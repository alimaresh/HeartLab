# دليل المناقشة السريع

## الفكرة في 30 ثانية

**HeartLab** تطبيق تعليمي لتقييم أعراض القلب. يجمع ثلاثة أجزاء مطلوبة في المادة داخل مسار واحد:

1. يستقبل العمر والجنس والنبض والضغط وSpO₂ وإجابات عشرة أسئلة.
2. يحول نموذج NLP وصف المستخدم العربي أو الإنجليزي إلى إجابات أعراض قابلة للمراجعة.
3. يصنف نموذج ML الحالة ضمن أربعة أنماط قلبية.
4. يطبق نظام خبير بقواعد IF/THEN ليقرر: متابعة عادية، حجز موعد، تقييم عاجل اليوم، أو طوارئ.

الناتج **تقييم أكاديمي استرشادي** وليس تشخيصًا طبيًا.

## مخطط العمل

```text
القياسات + الأسئلة ───────────────┐
                                  ├─> Random Forest ─> المرض الأقرب ودرجة التوافق
وصف الأعراض ─> NLP ─> إجابات ────┘
                                  └─> Expert System ─> توصية زيارة الطبيب وأسبابها
```

## التقنيات المهمة

| الجزء | التقنية | سبب الاختيار |
| --- | --- | --- |
| GUI | Python Tkinter | واجهة سطح مكتب خفيفة تعمل محليًا ولا تحتاج خادمًا |
| Disease ML | Random Forest، عدد 400 شجرة | مناسب للعلاقات غير الخطية والخصائص الرقمية والثنائية، ويعطي درجات لكل فئة |
| NLP | Word TF-IDF + Character TF-IDF | يلتقط العبارات والكلمات ويتحمل اختلاف كتابة العربية |
| NLP Classification | عشرة نماذج Logistic Regression داخل MultiOutputClassifier | يستخرج أكثر من عرض من الجملة نفسها ويحدد: موجود، منفي، أو غير مذكور |
| Expert System | قواعد Python صريحة IF/THEN مع أولوية | القرار قابل للتفسير، وتظهر أسباب التوصية للمستخدم |
| حفظ النماذج | Joblib | تحميل النموذجين المدربين من دون إعادة التدريب عند كل تشغيل |
| التوثيق | Markdown + MkDocs | توثيق أكاديمي قابل للبناء والعرض في المتصفح |
| الاختبارات | Pytest | التحقق من التدريب وNLP والقواعد والواجهة وبيانات العرض |

## نموذج تصنيف الأمراض

### البيانات

- المصدر: **DDXPlus** بترخيص CC BY 4.0.
- البيانات اصطناعية مبنية من قاعدة معرفة طبية، وليست سجلات مرضى حقيقيين.
- العينة المحضرة: **10,392 سجلًا**.
- بعد إزالة المدخلات المكررة: **5,118 سجلًا**.
- التدريب: **4,103 سجلات**.
- الاختبار المنفصل: **1,015 سجلًا**.

### الخصائص

يستخدم النموذج العمر والجنس وعشرة أعراض: ألم الصدر، ضيق التنفس، الخفقان، زيادة الأعراض مع المجهود، ارتفاع الضغط، الدوخة، التعرق، التعب، التورم، وسوء الأعراض عند الاستلقاء.

النبض وقراءات الضغط وSpO₂ تدخل في **قواعد النظام الخبير** لأنها غير موجودة كخصائص مقابلة في عينة DDXPlus المستخدمة. لم نخترع قيمًا غير موجودة في البيانات.

### الفئات الأربع

1. الذبحة الصدرية المستقرة.
2. الرجفان الأذيني.
3. اشتباه جلطة قلبية.
4. الوذمة الرئوية الحادة.

### التقييم

| المقياس | النتيجة |
| --- | ---: |
| Accuracy | 96.35% |
| Balanced Accuracy | 94.01% |
| Macro F1 | 93.96% |
| متوسط Macro F1 في 5-fold CV | 92.52% |

استخدمنا `GroupShuffleSplit` حسب متجه الخصائص الكامل، لذلك لا تظهر نفس المدخلات في التدريب والاختبار. قيمة التداخل المسجلة هي **صفر**.

## نموذج NLP الفعلي

- مجموعة التدريب: **396 جملة عربية وإنجليزية معنونة**.
- تقسيم القياس: 297 للتدريب و99 للاختبار.
- يعيد النموذج تدريب ملف التشغيل النهائي على كل الجمل بعد حساب مقاييس الاختبار المنفصل.
- Exact Match Accuracy: **75.76%**.
- Macro F1 العام: **93.22%**.
- لا يعتمد التطبيق اقتراحًا تقل ثقته عن **75%**.
- يعرض الاقتراحات للمستخدم كي يراجعها قبل نقلها إلى الأسئلة.

هو نموذج NLP مدرب فعلًا؛ لا تعتمد النتيجة على `if كلمة موجودة في النص` فقط. يستخدم تمثيل TF-IDF ثم مصنفات Logistic Regression متعددة المخرجات.

## النظام الخبير

كل قاعدة لها معرف ومستوى وسبب. أمثلة:

```text
IF SpO₂ < 90 THEN urgent
IF chest_pain AND shortness_of_breath THEN urgent
IF pulse > 100 OR pulse < 50 THEN appointment
IF unknown_symptoms THEN appointment
```

الأولوية هي: **طوارئ ← عاجل اليوم ← حجز موعد ← متابعة عادية**. إذا تحققت عدة قواعد يختار النظام أعلى مستوى، ثم يعرض أسباب القواعد الموجودة في ذلك المستوى.

## التعامل مع الحالات غير المعروفة

إذا كتب المستخدم أعراضًا لا يتعرف عليها NLP، وكانت إجابات أعراض القلب كلها سلبية:

- لا يجبر التطبيق Random Forest على اختيار مرض من الأمراض الأربعة.
- يعرض **«حالة غير معروفة للنظام»**.
- تفعل القاعدة `A09` توصية **حجز موعد مع الطبيب**.

هذا السلوك مهم لأن النموذج مغلق على أربع فئات ولا يحتوي فئة عامة لكل أمراض الجسم.

## الفرق بين الأجزاء الثلاثة

- **NLP:** يفهم النص ويستخرج الأعراض.
- **ML:** يتعلم الأنماط من البيانات ويرتب الأمراض المعروفة.
- **Expert System:** يطبق معرفة واضحة لاتخاذ توصية الزيارة، حتى لو كانت درجة ML غير حاسمة.

لا يلغي ML قواعد الخطر. مثال: تشبع أكسجين 88% يعطي توصية عاجلة حتى لو كان تصنيف المرض غير مؤكد.

## عرض المشروع أمام الدكتور

1. افتح **بيانات اختبار ← الذبحة الصدرية المستقرة ← نمط واضح**.
2. وضح المدخلات والأسئلة والرسم المتغير حسب BPM.
3. اضغط **تحليل الحالة** واعرض المرض الأقرب ودرجة التوافق وتوصية الطبيب.
4. افتح مثال الرجفان الأذيني لتوضيح أن النموذج متعدد الفئات.
5. افتح **اختبارات خارج النطاق ← صداع وحساسية للضوء**.
6. اضغط تحليل NLP ثم تحليل الحالة، واعرض «حالة غير معروفة للنظام» والقاعدة `A09`.
7. استخدم **بيانات عشوائية جديدة** لإثبات أن القيم ليست نتيجة ثابتة محفوظة.

## أسئلة متوقعة وإجابات قصيرة

### لماذا اخترت Random Forest؟

لأن البيانات تجمع العمر والجنس وأعراضًا ثنائية، والعلاقات بينها ليست خطية بالضرورة. Random Forest مناسب لحجم المشروع، قوي، وسهل التقييم والمناقشة.

### لماذا لم تستخدم Deep Learning؟

حجم البيانات النصية صغير وهدف المشروع أكاديمي قابل للتفسير. TF-IDF مع Logistic Regression يعطي نموذجًا فعليًا وأخف وأسهل لإعادة التدريب.

### هل الدرجة المعروضة احتمال إصابة حقيقي؟

لا. هي درجة توافق بين المدخلات وأنماط بيانات التدريب، وليست احتمالًا سريريًا معتمدًا.

### كيف منعت Data Leakage؟

أزلنا التكرار وقسمنا البيانات حسب متجه الخصائص الكامل. أي مدخلات متطابقة تبقى في جانب واحد فقط من التدريب أو الاختبار.

### لماذا تستخدم Balanced Accuracy وMacro F1؟

لأن أعداد سجلات الفئات ليست متساوية. هذان المقياسان يعطيان كل فئة وزنًا مناسبًا ولا يسمحان للفئة الأكبر بإخفاء ضعف الفئات الأصغر.

### ماذا يحدث إذا كانت كل الإجابات سلبية؟

إذا لم يكتب المستخدم أعراضًا خارج النطاق، يعرض النظام «لا توجد مؤشرات كافية». لا يصنف الحالة كمرض لأن بيانات الأمراض لا تحتوي فئة سليمة.

### ماذا يحدث عند إدخال مرض لا يعرفه النظام؟

يعرض «حالة غير معروفة للنظام» ويوصي بزيارة الطبيب، بدل اختيار أقرب مرض بالقوة.

### ما فائدة النظام الخبير مع وجود ML؟

ML يكتشف نمط المرض، بينما القواعد تحدد أولوية التصرف وتضمن أن علامات الخطر لا تضيع بسبب درجة النموذج.

## أوامر سريعة

```powershell
# تشغيل التطبيق
.venv\Scripts\python.exe app.py

# تشغيل الاختبارات
.venv\Scripts\python.exe -m pytest -q

# إعادة تدريب NLP
.venv\Scripts\python.exe scripts\build_nlp_dataset.py
.venv\Scripts\python.exe -m heart_app.nlp_model

# إعادة تدريب مصنف الأمراض
.venv\Scripts\python.exe scripts\prepare_ddxplus.py
.venv\Scripts\python.exe -m heart_app.diagnosis

# بناء التوثيق
.venv\Scripts\python.exe -m mkdocs build --strict
```
