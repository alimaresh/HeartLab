# نموذج تصنيف الأمراض

## البيانات

المصدر هو DDXPlus المنشور مع ورقة NeurIPS 2022. اختيرت أربع حالات قريبة من فكرة المشروع، وحُولت عشرة أدلة ثنائية إلى أسئلة مفهومة. العينة المحفوظة تضم 10,392 سجلًا؛ وبعد إزالة التكرار بقي 5,118 سجلًا للتدريب والتقييم.

## التدريب

- الخوارزمية: Random Forest من 400 شجرة.
- الخصائص: العمر، الجنس، وعشرة أعراض.
- التقسيم: GroupShuffleSplit بنسبة 80/20.
- تجميع الصفوف حسب كامل متجه الخصائص يمنع ظهور نفس المدخلات في التدريب والاختبار.
- البذرة ثابتة: 42.

## النتائج

| المقياس | النتيجة |
| --- | ---: |
| Accuracy | 96.35% |
| Balanced accuracy | 94.01% |
| Macro F1 | 93.96% |
| متوسط Macro F1 في 5-fold CV | 92.52% |

التفاصيل ومصفوفة الالتباس في `models/disease_metrics.json`. لأن البيانات المختارة لا تحتوي فئة سليمة، يمنع التطبيق التصنيف عندما تكون كل الأعراض سلبية أو عندما تقل أعلى درجة عن 45%.
