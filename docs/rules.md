# النظام الخبير وقاعدة المعرفة

## تمثيل المعرفة

كل قاعدة لها معرّف، وفئة نتيجة، وقائمة شروط موصولة بـAND. كل شرط يتكون من اسم حقل ومقارن وعتبة.
الحقائق قياسات خام، مثل `age=63` و`chol=300`، وليست قيمًا مطبّعة.

| القاعدة | IF | THEN |
| --- | --- | --- |
| R01 | age > 56 AND chol > 280 | High |
| R02 | trestbps > 152 AND oldpeak > 3 | High |
| R03 | exang == 1 AND oldpeak > 3 | High |
| R04 | thalach < 126 | Medium |
| R05 | chol > 250 | Medium |
| R06 | age > 50 | Medium |
| R07 | trestbps < 128 AND chol < 220 | Low |
| R08 | thalach > 154 | Low |
| R09 | oldpeak < 1.8 | Low |
| R10 | exang == 0 | Low |

## مصدر العتبات

هذه أمثلة تعليمية من قواعد المستودع الأصلي، وليست إرشادات طبية موثقة.
حوّلناها من نطاقات التطبيع الثابتة في واجهته إلى وحدات خام:
age: 20–80، BP: 80–200، chol: 100–400، thalach: 70–210، oldpeak: 0–6.
مثلًا `age_normalized > 0.6` تصبح `age > 56`.

## محرك الاستدلال وحل التعارض

1. التحقق من صحة الحقائق المتاحة.
2. تخطي أي قاعدة ينقصها حقل، مع تسجيل الحقول الناقصة.
3. تفعيل جميع القواعد التي تتحقق شروطها وإضافة أدلة القياسات.
4. إذا فُعّلت قاعدة High فلها الأولوية؛ وإلا Medium؛ وإلا Low.
5. عند عدم تفعيل أي قاعدة تكون النتيجة Undetermined، وليست Low افتراضيًا.

دالة `infer` تسمح بمدخلات جزئية لإظهار القواعد الناقصة؛ خدمة الواجهة تتطلب اكتمال 13 حقلًا لتشغيل ES وML معًا.
النتيجة تحتوي `fired_rules` و`counts` و`skipped_rules` و`complete`.

## مثال

```python
from heart_app.rules import infer
result = infer({'age': 63, 'chol': 300})
print(result['final_risk'])  # High
print(result['fired_rules']) # R01, R05, R06 with observed values
```

وجود قاعدة Low إلى جانب High لا يلغي High. هذه أولوية رمزية وليست تصويتًا أو نسبة احتمال.
