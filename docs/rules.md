# النظام الخبير Rule-based ES

كل قاعدة تتكون من شرط IF ونتيجة THEN وسبب ظاهر للمستخدم. يختار المحرك أعلى مستوى مفعّل:

1. **طوارئ:** وجود أعراض شديدة أو مستمرة الآن.
2. **عاجل اليوم:** SpO₂ أقل من 90%، ضغط 180/120 أو أعلى، ألم صدر مع ضيق تنفس، خفقان مع دوخة، أو ضغط منخفض مع عرض قلبي.
3. **حجز موعد:** تصنيف مرضي حاسم، عرض قلبي، أعراض مع المجهود، ضغط مرتفع، نبض خارج 50–100، SpO₂ أقل من 95%، تورم مع تعب، أو سوء الأعراض عند الاستلقاء.
4. **متابعة عادية:** لا توجد قاعدة أعلى.

تعرض النتيجة معرفات القواعد مثل `U03` و`A06`، ولذلك يمكن للطالب شرح سبب القرار بدل عرض نتيجة صندوق أسود فقط.

تضيف القاعدة `A09` توصية بحجز موعد عندما يكتب المستخدم أعراضًا لا يتعرف عليها NLP، وتكون جميع أسئلة المجال القلبي سلبية. يسمي النظام النتيجة «حالة غير معروفة للنظام» ولا يجبر نموذج الأمراض على اختيار فئة لم يتدرب عليها.
