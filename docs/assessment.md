# التصنيف المبدئي وتوصية المراجعة

الواجهة الأساسية تشغّل الآن نموذجًا مستقلًا ملائمًا لمدخلاتها، بدل إعادة سردها.
تبدأ النتيجة بقرار المراجعة ووقتها، ثم التصنيف والنسبة التقديرية، ثم أسباب القرار.

## البيانات والنموذج

المصدر: [UCI Heart Disease](https://archive.ics.uci.edu/dataset/45/heart+disease)،
الملف الأصلي `hungarian.data` بإشراف Andras Janosi، بترخيص CC BY 4.0.
يعتمد النموذج على العمر والجنس والضغط الانقباضي ونبض **الراحة** وألم المجهود،
ويضيف الضغط الانبساطي عند توفره. ضيق التنفس وتاريخ ارتفاع الضغط يدخلان قواعد الفرز فقط.
الدلالة المستهدفة هي وجود مرض الشرايين التاجية بفحص الأوعية في مجموعة المصدر؛ ليست نوبة قلبية حالية.

293 سجلًا صالحًا من 294؛ التدريب 234 والاختبار 59 ببذرة 42 وتقسيم طبقي.
النموذج Logistic Regression بعد StandardScaler، مع معايرة sigmoid بخمس طيات داخل التدريب فقط.
لم تُستخدم نتائج الاختبار لاختيار المعلمات. عند غياب الضغط الانبساطي نستخدم نسخة بخمس خصائص،
وعند توفره نسخة بست خصائص، دون ملء قياسات المستخدم المفقودة بأرقام افتراضية.

| المقياس | خمس خصائص | ست خصائص |
| --- | --- | --- |
| Accuracy | 84.75% | 84.75% |
| Precision | 92.86% | 92.86% |
| Recall | 61.90% | 61.90% |
| ROC AUC | 0.8584 | 0.8534 |
| Brier score | 0.1304 | 0.1310 |

مصفوفة الالتباس: `[[37, 1], [8, 13]]`. أخفق النموذج في اكتشاف 8 من 21 حالة إيجابية.
هذه تجربة صغيرة على تقسيم واحد، وليست دليلًا على صلاحية تشخيصية. المعايرة داخل التدريب لا تجعل النسبة
احتمالًا شخصيًا معتمدًا؛ منحنى المعايرة وأعداد الاختبار في `artifacts/screening_metrics.json`.
المصدر قديم ومن مرضى أحيلوا للفحوصات؛ إجابة المستخدم عن ألم المجهود ليست مكافئة تمامًا لسجل الاختبار الأصلي.
لا يُستخدم الملف الخام Cleveland لأن أرشيف المصدر يحذّر من تلفه.

```bash
python -m heart_app.screening
```

يعيد الأمر التدريب من البيانات المرفقة دون الإنترنت. تبقى شجرة القرار الأصلية في قسم الفحوصات.
تُحجب النسبة إذا كانت القياسات المطلوبة ناقصة أو خارج المدى المشاهد في تدريب النموذج.

## قواعد المراجعة

هذه قواعد تعليمية محافظة مستندة إلى مصادر عامة؛ **ليست بروتوكول فرز سريريًا معتمدًا**.
سؤال علامات الخطر الحالية يستفسر عن ألم صدر مستمر أو ضيق نفس شديد أو إغماء.
إجابة نعم تُظهر طلب المساعدة الطارئة مباشرة، حتى لو كانت بقية الحقول ناقصة أو غير صالحة، ودون انتظار ML.

| النتيجة | أمثلة من قواعد التطبيق |
| --- | --- |
| مساعدة طارئة الآن | إجابة نعم عن سؤال علامات الخطر الحالية |
| تقييم عاجل اليوم | ضغط شديد الارتفاع، أو ضغط منخفض مع أعراض/نبض سريع، أو نبض غير معتاد مع أعراض |
| موعد طبي | ألم المجهود، ضيق التنفس، متابعة الضغط، أو تصنيف ML الإيجابي دون استعجال أعلى |
| معلومات غير كافية | قياسات الفرز أو سؤال الأعراض الحالية ناقصة، دون علامة أخرى تحدد الاستعجال |
| لا تظهر علامة عاجلة | اكتمال معلومات الفرز وعدم تفعيل قواعد التصعيد؛ لا يعني عدم وجود مرض |

العتبات: ضغط شديد `systolic>180 OR diastolic>120`؛ منخفض `systolic<90 OR diastolic<60`؛
نبض سريع `bpm>100`؛ متابعة ضغط `systolic>=140 OR diastolic>=90`.
اختيار مراجعة اليوم لبعض التركيبات، وحد النبض البطيء `<50`، وتوجيه موعد عند تصنيف ML الإيجابي
قرارات محافظة للمشروع وليست خوارزمية معتمدة من المصادر.
ضغط منفرد لا يثبت تشخيص ارتفاع الضغط. النسبة المنخفضة لا تلغي توصية تفعّلت بالأعراض.
لا يشمل الفرز الحمل أو الأطفال أو جميع علامات الطوارئ.

- [AHA: نبض القلب](https://www.heart.org/en/health-topics/high-blood-pressure/the-facts-about-high-blood-pressure/all-about-heart-rate-pulse): نبض الراحة والأعراض المصاحبة.
- [NHS: ارتفاع الضغط](https://www.nhs.uk/conditions/high-blood-pressure/): القياسات المتكررة وتفسيرها.
- [scikit-learn: المعايرة](https://scikit-learn.org/stable/modules/calibration.html): معايرة احتمالات المصنف وتقييمها.
