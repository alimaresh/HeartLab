# الاختبارات والتحقق

```bash
python -m ml_model.train_model
python -m heart_app.screening
python -m pytest -q
python -m mkdocs build --strict
```

يجب تدريب النموذج أولًا لأن اختبار الواجهة يستخدمه، بينما اختبار التدريب نفسه ينشئ نموذجًا مؤقتًا.

## التغطية

`test_assessment.py` يختبر تدريب النموذج الأساسي، النسبة، حجب القيم خارج التدريب، أولوية الطوارئ
حتى مع حقول ناقصة، وعدم إلغاء أعراض تستدعي المراجعة بسبب نسبة منخفضة.

| الجانب | حالات التحقق |
| --- | --- |
| Validation | NaN وinfinity والقيم خارج الحدود والفئات الخاطئة والحقول الناقصة |
| ES | الأولوية، الدليل، عتبة الحد، استقلال الحالات، غياب الحقائق |
| NLP | عربي/إنجليزي، أرقام عربية، النفي، التعارض، نص غير معروف |
| ML | عدم تداخل الصفوف، تدريب وحفظ وإعادة تحميل، ترتيب الحقول، نموذج مفقود |
| GUI | تحميل المثال، التنبؤ والتفسير، إبطال نتيجة قديمة، تطبيق NLP ومسح قيم الحالة السابقة |

اختبارات Tk تعمل بنافذة مخفية وتتجاوز نفسها إذا لم يتوفر display. يلزم فحص بصري يدوي لخطوط العربية وحجم الشاشة على جهاز العرض.
النجاح الوظيفي لا يثبت صحة القواعد طبيًا أو دقة NLP على نصوص حرة خارج القاموس.
