# HeartLab — مشروع النظام الخبير

تطبيق تعليمي يجمع أربع تقنيات: النظام الخبير القائم على القواعد، والتعلم الآلي، ومعالجة اللغة الطبيعية، وواجهة Python.
يمكن تشغيله محليًا بعد تثبيت المتطلبات، دون API أو اتصال بخدمة ذكاء اصطناعي.

## أهداف المشروع

- تحويل وصف نصي بالعربية أو الإنجليزية إلى حقائق قابلة للمراجعة.
- تطبيق قواعد معلنة وشرح سبب تفعيلها.
- تدريب نموذج Decision Tree من البيانات، ومقارنة نتيجته باستدلال القواعد.
- تقديم تطبيق مكتبي وتوثيق يمكن شرحهما في مناقشة المادة.

ابدأ بـ[التثبيت](setup.md)، ثم [دليل الاستخدام والعرض](user-guide.md).
للتفاصيل: [المعمارية](architecture.md)، [القواعد](rules.md)، [ML](ml.md)، [NLP](nlp.md).

## حدود الاستخدام

الفئات High/Medium/Low تسميات تعليمية موروثة من أمثلة المشروع الأصلي.
درجة ML ليست احتمالًا طبيًا معايرًا، ودلالة target السريرية لم تُتحقق من مصدر البيانات الأصلي.
لا تصلح النتائج لتشخيص شخص أو اختيار علاج. لا حاجة لإدخال أسماء أو بيانات تعريفية في العرض.
