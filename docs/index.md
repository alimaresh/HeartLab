# HeartLab

HeartLab مشروع مادة Expert System يجمع المتطلبات في شاشة واحدة سهلة العرض والمناقشة. يدخل المستخدم العمر والجنس والنبض والضغط وتشبع الأكسجين، ثم يجيب عن عشرة أسئلة أو يكتب وصفًا حرًا للأعراض.

يعالج نموذج NLP النص ويقترح إجابات قابلة للمراجعة. بعد ذلك يصنف نموذج ML نمط الحالة بين أربعة أمراض قلبية، ويطبق النظام الخبير قواعد IF/THEN ليقرر هل توجد حاجة إلى موعد أو تقييم عاجل أو مساعدة طارئة.

درجات الأمراض هي مخرجات النموذج على بيانات DDXPlus الاصطناعية، وليست احتمالات إصابة سريرية.
