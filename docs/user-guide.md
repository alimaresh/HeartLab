# دليل الواجهة والعرض

1. أدخل العمر والجنس وBPM والضغط الانقباضي والانبساطي وSpO₂.
2. أجب عن الأسئلة العشرة بنعم أو لا.
3. يمكنك كتابة الأعراض والضغط على **تحليل النص بنموذج NLP**، ثم مراجعة المقترحات واستخدامها.
4. اضغط **تحليل الحالة** لعرض التصنيف المرتب وتوصية الزيارة وأسباب القواعد.

تحتوي قائمة **بيانات اختبار** على حالتين مختلفتين لكل مرض في النموذج، وحالة مستقرة، وحالة طوارئ. كما تحتوي اختبارات خارج النطاق للصداع النصفي والأعراض الهضمية، وحالة أعراض متداخلة، ومولدًا عشوائيًا ينشئ قياسات وإجابات جديدة عند كل ضغطة. تعيد القائمة تعبئة الشاشة نفسها ولا تفتح نافذة منفصلة.

أمثلة خارج النطاق مقصودة لاختبار سلوك الرفض: يعرض النظام «حالة غير معروفة للنظام» ويوصي بزيارة الطبيب عندما يكتب المستخدم أعراضًا لا يعرفها وتكون أسئلة القلب سلبية، بدل اختيار مرض قلبي بالقوة.

للشرح أمام الدكتور: ابدأ بحالة الموعد، اعرض كيف استخرج NLP أكثر من عرض، ثم شغّل التحليل واشرح الفرق بين درجة ML وبين قرار القواعد. قرار القواعد لا يُلغى إذا كانت درجة ML منخفضة.
