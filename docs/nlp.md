# نموذج NLP الفعلي

NLP هنا نموذج مدرب، وليس قائمة كلمات تعيد نتيجة مباشرة. تبدأ العملية بمجموعة `data/nlp/symptom_texts.csv` التي تحتوي 396 جملة عربية وإنجليزية معنونة بعشر حالات أعراض، ولكل عرض ثلاث قيم: موجود، منفي صراحة، أو غير مذكور.

يمثل النص بطريقتين معًا:

- Word TF-IDF حتى 3-grams لفهم العبارات والنفي.
- Character TF-IDF من 3 إلى 5 محارف لتحمل اختلاف الكتابة العربية.

تُدرب عشرة مصنفات Logistic Regression مستقلة داخل `MultiOutputClassifier`. في اختبار 25% منفصل حقق النموذج Exact Match قدره 75.76% وMacro F1 كليًا قدره 93.22%. بعد قياس الاختبار يعاد تدريب ملف التشغيل على كل الجمل المتاحة.

يعرض التطبيق الإجابات المقترحة والثقة، ويطلب مراجعتها قبل نقلها إلى أزرار نعم/لا. هذا مناسب لحجم مشروع المادة ويبين دورة بيانات وتدريب وتقييم كاملة.
