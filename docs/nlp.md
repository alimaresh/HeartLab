# معالجة اللغة الطبيعية NLP

## النوع المنفذ

NLP رمزي لاستخراج المعلومات: تطبيع Unicode، تحويل الأرقام العربية والفارسية، مطابقة كيانات وقيم،
وكشف نفي محدود السياق. هذا ليس LLM أو فهمًا حرًا لكل النصوص، ولا يحتاج بيانات تدريب نصية.

## مثال إنجليزي

```text
Age 63, blood pressure 160, cholesterol 300, maximum heart rate 120, oldpeak 3.5.
No exercise angina. Dizziness.
```

يستخرج age=63، trestbps=160، chol=300، thalach=120، oldpeak=3.5، exang=0.
يحتفظ بالدوخة كعرض سياقي؛ لا يخمن فئة cp أو نتيجة ECG.

## مثال عربي

```text
العمر ٦٣، ضغط الدم ١٦٠، الكوليسترول ٣٠٠، أقصى نبض ١٢٠، oldpeak ٣٫٥.
لا يوجد ألم الصدر مع المجهود.
```

## القاموس

| الحقل | أمثلة أسماء مدعومة |
| --- | --- |
| age | age, aged, العمر, عمري, عمره, عمرها |
| trestbps | blood pressure, resting blood pressure, bp, ضغط الدم, الضغط |
| chol | cholesterol, chol, الكوليسترول |
| thalach | maximum heart rate, max heart rate, أقصى نبض |
| oldpeak | oldpeak, st depression |
| رموز أخرى | sex, cp, fbs, restecg, exang, slope, ca, thal يليها رقم |

الأعراض المدعومة: ألم الصدر، ضيق التنفس، الدوخة، التعب، وذبحة المجهود بصيغ محددة في القاموس.
كلمات النفي تشمل no/without/denies ولا/بدون/ينفي. ينتهي سياق نفي الأعراض عند علامات الفصل أو but/لكن.

## مراجعة وعدم افتراض

- تُعرض العبارات التي استند إليها الاستخراج.
- إذا ورد عمر 40 ثم عمر 60 لا يختار أحدهما؛ يظهر تحذير ويترك الحقل فارغًا.
- القيمة خارج المجال تُرفض.
- عدم ذكر العرض لا يعني نفيه.
- لا يتحول ألم الصدر العام إلى exang=1؛ يلزم نص صريح عن المجهود.
- تطبيق النتائج يستبدل الحالة السابقة، ثم يُطلب إكمال الحقول الناقصة قبل ML.

## الحدود

اكتب الأعداد بالأرقام لا بالكلمات، وقياسًا واحدًا لكل حقل، وبالوحدات المعروضة في النموذج.
لا يدعم النص المركب ذو النفي البعيد، التاريخ العائلي، المقارنات الزمنية، تحويل الوحدات أو فهم اللهجات عمومًا.
مثلًا النبض العادي ليس مرادفًا لأقصى نبض أثناء اختبار المجهود.
Tkinter يقبل النص العربي Unicode؛ جودة اتجاه النص وتشكيله تعتمد على Tk والخط ونظام التشغيل.

الاختبارات تتضمن العربية والإنجليزية والنفي والتعارض والأرقام، لكنها ليست تقييمًا على مجموعة نصوص سريرية مستقلة.
